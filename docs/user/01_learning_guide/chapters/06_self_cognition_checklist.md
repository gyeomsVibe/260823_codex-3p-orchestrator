# ✅ 제6장: 나의 프로젝트 인지 셀프 체크리스트

다음 5가지 질문에 모두 `[V]` 체크할 수 있다면, 여러분은 "모르는 걸 모르는 상태"에서 "무엇을 알고 모르는지 명확히 아는 상태"로 완벽히 전환된 것입니다.

- [ ] **1. 3대 AI의 한 몸 협업을 이해했는가?**
  - Codex, Claude Code, Antigravity가 따로 노는 것이 아니라, 하나의 유기체처럼 서로를 감시하며 작동함을 이해했다.
- [ ] **2. 각 도구의 담당 역할을 아는가?**
  - Codex는 두뇌(계획/단일보고), Claude는 면역계(코딩/보안), Antigravity는 손과 눈(화면/실측)임을 안다.
- [ ] **3. '근거 없는 초록불'을 거부하는 이유를 아는가?**
  - AI가 가짜 성공을 말하지 못하도록, 실제 종료코드 0과 파일 확인 데이터가 있어야만 성공으로 친다는 점을 안다.
- [ ] **4. 5대 인간 필수 승인 영역(P2)을 알고 있는가?**
  - 파일 삭제, 패키지 설치, Git 푸시, DB 파괴, 시크릿 수정은 반드시 내(사람) 승인이 있어야만 실행됨을 안다.
- [ ] **5. 언제든 내가 시스템 실기동을 요청하고 상태를 확인할 수 있는가?**
  - `c3p 발동` 명령어로 3도구 실기동을 요청하고, `python csc.py status` 및 `.agent-swarm/dashboard.html`에서 실제 연결·회신을 정직하게 확인할 수 있음을 안다.
