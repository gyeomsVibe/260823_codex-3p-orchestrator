# 🚀 제5장: 실전 조작 및 치트키 가이드

## 1. 기본 발동 명령어
- `c3p 발동` (대소문자 무관): 세 AI(Codex, Claude, Antigravity)를 동시 가동하여 협업 체계를 시작하고, 프로젝트 전용 `.agent-swarm/dashboard.html`을 최신 스냅샷으로 갱신합니다.
- `이 프로젝트 점검해서 교정해줘` (원터치 vibe-check): 자가진단 스킬을 발동하여 오류를 자동 탐색하고 최소 단위로 안전하게 교정합니다.

## 2. GPT 실전 치트키 10선
| 치트키 | 핵심 기능 | 추천 사용 시점 |
|---|---|---|
| `/DEEPDIVE` | 1차 자료와 증거를 끝까지 파고들어 심층 분석 | 원인 분석이나 정밀 기술 검토가 필요할 때 |
| `/SELFREFINE` | 스스로 기준표에 대조해 결함을 찾아 2차 정제 | 산출물의 완성도를 한 단계 더 끌어올릴 때 |
| `/OPTIMIZE` | 목표를 높이면서 제약을 지키는 최소 변경 최적화 | 성능 개선, 코드 경량화, UI 가독성 개선 |
| `/REDTEAM` | 적대적 해커/비판자 시선에서 실패 시나리오 탐색 | 배포 직전 보안 구멍이나 예외 상황을 찾을 때 |
| `/ELI10` | 초등학생(10세)도 알아들을 수 있게 비유로 설명 | 어려운 기술 용어가 나와 이해가 안 될 때 |
| `/CRITIC` | 칭찬이나 아첨 없이 객관적 결함만 냉정히 지적 | 설계나 코드의 숨은 맹점을 점검하고 싶을 때 |
| `/STEPBYSTEP` | 사용자가 따라 할 수 있는 번호 매겨진 절차 제공 | 복잡한 실행 순서나 튜토리얼이 필요할 때 |
| `/ALT3` | 서로 다른 메커니즘을 가진 대안 3가지 비교 | 주요 의사결정에서 여러 선택지를 비교할 때 |
| `/EXPERT` | 해당 분야 최고 전문가의 기준과 리스크 모델 적용 | 높은 신뢰도가 요구되는 전문 결정을 내릴 때 |
| `/STRUCTURED FEW-SHOT` | 예시의 형식과 스키마를 새 입력에 일관 적용 | 보고서나 산출물의 출력 규격을 엄격히 맞출 때 |
