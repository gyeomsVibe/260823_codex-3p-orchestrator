# Swarm Meal MVP 기능 명세 초안

상태: 사용자 선택 대기

## 고정 요구사항

- 별도 서버와 외부 네트워크 요청이 없는 단일 HTML
- 한식·중식·일식·양식·간식 5개 카테고리
- 메뉴명, 큰 이모지, 한 줄 설명
- 최초 추천과 다시 추천 버튼
- 최신순 최근 추천 3개
- 375×667 화면에서 가로 스크롤 없이 44×44px 이상 터치 타깃
- `?selftest=1`에서 기능 검증 결과 표시
- `Codex 구현 · Claude Code 검토 · Antigravity UX 검증` 정적 크레딧
- `v0.1 · 2026-08-23` 버전 표기

## 권고 기본값

- 이력 저장: `localStorage`로 새로고침 후에도 유지
- 중복 정책: 연속으로 같은 메뉴가 나오지 않도록 하고, 이력에는 실제 화면에 표시된 추천을 최신순으로 기록
- 범위: 첫 MVP는 앱과 자체 검증까지만; GitHub·Render·Ollama는 다음 승인 게이트

## 구현 전 사용자 결정

첫 가시적 결과물을 위 권고 기본값으로 바로 구현할지, 세 도구가 같은 앱을 각각 별도 폴더에 만들어 비교할지 결정한다. 권고안은 **단일 앱 + 역할 분담**이다. 동일 앱 3벌 제작은 비교는 쉽지만 시간과 충돌 위험이 커진다.
