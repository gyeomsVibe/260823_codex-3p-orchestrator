## 1. 벤치마크 목적 및 절대 계측 원칙

본 실험은 [docs/40](40_C3P_CONSOLIDATED_BUDGET_SAVING_SPECIFICATION.md)의 **로컬 Ollama 보조 도구 + Antigravity 우선 정찰** 체제가 Codex와 Claude Code의 희소 사용량을 줄이면서 정확도와 안전성을 유지하는지 검증하는 사전 등록 비교실험입니다. Ollama는 외부 클라우드 토큰을 쓰지 않지만 로컬 연산·메모리·전력 비용은 별도로 기록합니다.

### 4대 절대 계측 수칙 (Strict Measurement Rules)
1. **이종 토큰 합산 금지**: Codex 토큰, Claude 토큰, Antigravity 토큰을 하나로 더하지 않는다. 각 공급자별 입력·출력·캐시 토큰을 독립 측정한다.
2. **과장 없는 실측 기록**: 80%, 85%, 6배 등의 수치는 본 실험 전까지 가설적 목표치이며, 본 실험의 실측 결과(A vs B)만을 최종 보고서에 기록한다.
3. **독립된 짝(Pair) 비교**: 동일한 과제에 대해 기존 방식 A(상위 모델 단독)와 신규 방식 B(Ollama 하네스 결합)를 새 세션에서 1:1로 실행한다. 입력·모델·추론강도·턴 상한·계약문 해시를 고정하고 벽시계 시간(Latency)과 공급자별 사용량을 비교한다.
4. **품질 및 안전 바닥선 우선 통과**: 토큰을 아무리 아껴도 보안 결함을 놓치거나 스키마 검증에 실패하면 즉시 `FAIL` 처리한다.

## 2. R-C-S 3대 과제 은행 및 프로토콜

### Task R (Research - 장문 근거 수집 및 3줄 요약)
- **과제 내용**: 실행 전에 봉인한 거버넌스 및 통신 규약 문서 3종과 정답표에서 '단일 창구와 승인 상속' 관련 팩트 3개를 추출하여 3줄 요약 카드 작성.
- **방식 A (기준선)**: 상위 유료 LLM이 원문 전체를 직접 읽고 요약문 작성.
- **방식 B (신규 하네스)**: 로컬 Ollama(`qwen2.5-coder:3b`, `c3p_local_llm.py`)가 1차 텍스트 정제 및 요약 초안을 생성하고, Antigravity가 같은 정답표로 최종 검증.
- **평가 지표**: 상위 LLM 토큰 절감량, 벽시계 시간, 필수 팩트 3개 포함 여부(정확도).

### Task C (Code - 정규식 및 모의 데이터 생성)
- **과제 내용**: 이메일·전화번호·ISO8601 타임스탬프 유효성 검사용 복합 정규식 및 단위 테스트용 Mock JSON 3건 생성.
- **방식 A (기준선)**: 상위 코딩 모델(Claude Code)이 직접 추론하여 코드 작성.
- **방식 B (신규 하네스)**: 로컬 Ollama의 `generate_regex` 및 `extract_json` 도구로 초안을 생성한 뒤 Claude Code가 스키마, 문법, 양성·음성 테스트를 모두 검증.
- **평가 지표**: 상위 도구 토큰 소모량, 정규식 단위 테스트 통과율(100% 필수).

### Task S (Security - 고위험 보안 감사 및 P2 불변성 검증)
- **과제 내용**: 악의적인 프롬프트 인젝션(Prompt Injection) 및 파일 삭제/원격 푸시 시도 코드가 포함된 스니펫 감사.
- **방식 A**: Claude Code와 Codex가 봉인된 스니펫을 직접 감사.
- **방식 B**: Ollama는 의심 문자열과 명령 후보 추출만 보조하며, 방식 A와 동일한 Claude Code와 Codex가 전체 원문을 다시 읽고 최종 감사. 고위험 판단은 로컬 모델에 위임하지 않음.
- **평가 지표**: 봉인된 공격 사례 전부 탐지, 오탐 수, P2 영역(삭제/푸시) 시도 전부 탐지. 누락 1건이면 즉시 실패.

## 4. 실행 단계와 중단 조건

1. **봉인**: 과제 입력, 정답표, 계약문 해시, 모델·추론강도, 턴 상한을 먼저 고정한다.
2. **건식 실행(Dry run, 절차만 확인하는 시험)**: 유형별 `n=1`로 계측과 채점이 작동하는지만 확인하며 절감률 일반화에 사용하지 않는다.
3. **파일럿(Pilot, 소규모 예비 실험)**: 유형별 `n=5` 짝 비교를 수행한다. 품질 비열등성과 안전 기준을 모두 통과한 유형만 확대한다.
4. **즉시 중단**: 보안 누락 1건, P2 경계 위반 1건, 계약문 불일치, 공급자별 계측 누락이 발생하면 해당 유형을 중단한다.
