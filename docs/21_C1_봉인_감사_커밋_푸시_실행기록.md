# C1 봉인·감사·커밋·푸시 실행 기록

## 한 문장으로 설명

세 AI가 협업하는 시스템에서 **없는 찬성표를 세거나 확인하지 않은 성공을 보여 주는 문제**를 고치고, 검사·봉인·표결·사용자 승인 순서로 공개 저장소에 올릴 후보를 만들었다.

## 초보자를 위한 비유

이 프로젝트를 세 사람이 함께 쓰는 우편실이라고 보면 된다.

- `.agent-swarm`은 편지함과 업무 일지다.
- `csc.py`와 브로커·워커는 편지를 전달하는 직원이다.
- 감사기(auditor)는 “보냈다”, “통과했다”, “모두 찬성했다”는 말이 실제 기록과 같은지 확인하는 검표원이다.
- 봉인(seal)은 택배 상자를 닫고 내용물의 지문인 Git 트리 해시를 붙이는 일이다.
- 사용자 승인은 봉인된 상자를 외부 저장소로 보내도 된다는 최종 허가다.

## MIA 전략 판정

| 단계 | 판단 |
|---|---|
| 기획(Frame) | 목표는 기능 추가보다 **검증되지 않은 성공 표시와 유령 투표를 막은 상태로 최초 공개 이력을 만드는 것**이다. |
| 검토(Review) | 가치: 사용자가 실제 협업 상태를 볼 수 있다. 실현 가능성: 외부 패키지 없이 Python과 Git으로 검증했다. 지속 가능성: 원문과 사용자 화면을 분리했다. 위험: 두 동료 도구가 마지막 해시에 투표하지 못했다. |
| 실행(Execute) | 등록된 투표자만 집계하고, 대시보드의 가짜 표를 제거하고, 발신 전 주장 감사와 2단계 봉인을 적용했다. |
| 검증(Verify) | 전체 단위 테스트 121개와 감사·결정·증거·정족수·동기화 자체검사를 다시 실행했다. 판정은 **사용자 승인 범위에서 진행(Go)** 이다. |

## 심각도순 진단과 해결

### 1. 매우 심각: 등록되지 않은 이름도 투표자로 셌다

- **근거:** `ghost1`, `ghost2` 같은 유령 이름의 찬성표만으로 승인되는 재현 사례가 있었다.
- **영향:** 실제 세 도구가 동의하지 않아도 승인됐다고 표시할 수 있었다.
- **해결:** `csc_decide.py`가 등록된 구성원과 허용된 표만 받도록 바꾸고 회귀 테스트를 추가했다.
- **검증:** Claude Code가 Codex의 테스트를 그대로 믿지 않고 유령 이름·대소문자 우회를 다시 시험해 차단을 확인했다.

### 2. 매우 심각: 대시보드가 존재하지 않은 Claude 찬성표를 만들었다

- **근거:** 대시보드 코드에 실제 메시지와 연결되지 않은 `votes={"claude":"AGREE"}`가 있었다.
- **영향:** 사용자는 토론과 투표가 실제로 끝났다고 오해할 수 있었다.
- **해결:** 근거가 없을 때는 `판정 미검증`으로 표시하도록 바꿨다.
- **검증:** 결정 무결성 테스트 5개를 추가하고 전체 테스트에 포함했다.

### 3. 심각: 감사기가 자기 실패를 숨기거나 정상 기록을 막았다

- **근거:** Git 명령 실패를 빈 결과처럼 처리했고, 계정명을 소스에 직접 넣었으며, 인용문·`jsonl` 확장자·파일명만 쓴 참조를 잘못 판정했다.
- **영향:** 감사기가 거짓 안전 신호를 만들거나 정직한 보고를 차단할 수 있었다.
- **해결:** Git 사용 불가를 별도 상태로 올리고, 계정명은 실행 환경에서 얻으며, 인용 문맥·확장자 순서·파일명 탐색을 고쳤다.
- **검증:** `csc_audit.py --selftest` 9/9 통과. 발신 경로와 사용자 대시보드에도 감사 결과를 연결했다.

### 4. 높음: “동결”을 기록하는 행위가 후보를 다시 바꿨다

- **근거:** 동결 선언 로그까지 추적 후보에 들어가면서 앞서 계산한 해시가 여러 번 낡았다.
- **영향:** 검토한 내용과 실제 커밋할 내용이 달라질 수 있었다.
- **해결:** 동료가 쓰기를 멈춘 뒤 Codex가 `git write-tree`로 봉인하고, 봉인 메시지는 Git에서 제외된 원문 큐에만 남기는 2단계 절차를 사용했다.
- **검증:** 최초 후보 해시 `9737baa77fddf5a3f707a76beeecf84063df106d`를 여러 번 다시 계산해 일치를 확인했다. 이후 사용자가 설명형 파일명 정리를 지시했으므로 그 봉인은 의도적으로 해제했고, 최종 후보는 모든 검사 후 새 해시로 다시 봉인한다.

### 5. 높음: 마지막 봉인 후보의 동료 표결을 채우지 못했다

- **근거:** Claude Code는 사용량 한도 소진, Antigravity는 안전한 계획·샌드박스 실행에서 관리자 권한 상승이 자동 거부됐다.
- **영향:** 찬성 1표, 기권 2표로 전체 구성원 과반인 2표에 미달했다.
- **해결:** 기권을 찬성이나 반대로 바꾸지 않고 사유와 식별자를 기록했다. 거버넌스 13-5에 따라 사용자에게 올렸고 사용자가 커밋·푸시를 명시적으로 승인했다.

## Claude Code 원문을 참고한 방법

사용자가 지정한 대화창 `2608023_3대 AI 병렬 협업 시스템 구축_claude code`의 로컬 JSONL 원문 두 세션을 직접 읽었다.

| 세션 | 관찰 범위 | 이 보고서에 반영한 내용 |
|---|---|---|
| 장기 세션 | 2026-08-23~2026-09-05, 3,153행 | 낡은 상태표, 자기 사건 종결 금지, Windows 생존 판정 오류, 사용자용 감시 화면 요구 |
| 마감 세션 | 2026-09-05, 1,498행 | 유령 투표 재현, 가짜 대시보드 표 확인, 2단계 봉인 제안, 주장 감사기 구현·자가비판, 마지막 사용량 한도 종료 |

원문에서 반복된 설명 구조인 **문제 → 실측 증거 → 영향 → 조치 → 재검증 → 남은 한계**를 이 문서의 고정 형식으로 사용했다. 로컬 Claude 대화 원문은 참고자료이며 저장소에 복사하지 않았다. 프로젝트 안에서 공개 가능한 협업 기록은 [Claude Code 세션 기록](../.agent-swarm/chat/sessions/claude-code-6c.md)과 [결정 무결성 검토](../.agent-swarm/results/04_DECISION_INTEGRITY_REVIEW.md)에 남아 있다.

## 작업 도중 발생한 오류와 교정

| 오류 | 숨기지 않고 처리한 방법 |
|---|---|
| 샌드박스에서 `git write-tree`가 인덱스 잠금 권한 오류 | 실제 Git 권한 경계에서 다시 실행해 같은 해시를 확인했다. |
| “정족수 미달” 보고가 감사 규칙의 합의 표현 오탐에 걸림 | 찬성·기권 수와 각 메시지 식별자를 직접 적어 다시 발신하고 저장본을 되읽었다. |
| Claude JSONL 구조 추출용 Python 명령의 줄바꿈 인용 실패 | 실패 종료코드를 인정하고 PowerShell JSON 파서로 바꿔 두 세션을 측정했다. |
| 긴 한글 이름 파일 하나의 이동이 접근 거부 | 새 파일을 복사한 뒤 SHA-256이 같은지 확인하고, 권한 경계에서 이전 이름만 제거했다. |

## 파일과 폴더 이름 정리

실행 코드와 테스트는 기존 이름만으로 역할을 알 수 있어 유지했다. 사용자 원자료·초안·스크린샷은 `docs/reference-materials/`로 모으고 `u00`, `u01`, `no3`, 오탈자처럼 맥락 없이는 알 수 없는 이름을 설명형 이름으로 바꿨다. 전체 대응표는 [참고자료 인덱스](reference-materials/README.md)에 있다.

정본 프로젝트 루트 `260823_codex-3p-orchestrator`는 프로젝트 규칙이 고정한 물리 경로이므로 바꾸지 않았다.

## 남은 한계

- Claude Code와 Antigravity는 최종 이름 정리 후의 새 트리 해시를 독립 검토하지 못했다.
- 문자열 패턴 검사는 알려지지 않은 모든 개인정보·비밀정보의 부재를 증명하지 않는다.
- 전체 `git diff --cached --check`에는 Markdown에서 의도한 두 칸 줄바꿈이 공백 경고로 잡힌다. 코드·데이터 파일의 공백 검사는 별도로 통과했다.
- 커밋 해시는 커밋 내용에 자기 자신의 해시를 넣을 수 없으므로 이 문서에 기록하지 않는다. Git 실행 후 로컬 `HEAD`와 `origin/main`을 직접 대조한다.

## 사용자가 확인할 것

커밋·푸시 뒤에는 다음 세 가지가 모두 맞아야 끝난다.

1. 로컬 `HEAD`와 `origin/main`의 커밋 해시가 같다.
2. 미스테이징·미추적 파일이 없고, 런타임 로그와 캐시는 무시 상태다.
3. 필수 경로인 `.agent-swarm`, `.agents`, `.claude`, `app`, `docs`, `tests`가 원격 커밋에 들어 있다.
