# 세 도구 한 유기체 거버넌스

작성일: 2026-08-23 KST

## 결정

Codex, Claude Code, Antigravity는 최종 산출물·commit·push를 각자 따로 수행하지 않는다. 세 도구는 역할이 다른 하나의 유기체로 운영하고 Codex가 조율한다.

## 기관별 역할

- Codex(뇌): 목표·업무 분해, 사용자 대화, 승인 경계, 통합, 최종 실행.
- Claude Code(면역계): 오류·보안·회귀·테스트 검증과 차단.
- Antigravity(손과 눈): 구현 대안, IDE·브라우저 실물, 초보자 UX 확인과 차단.
- 안전 규칙·사용자 승인(자율신경): 누구도 우회할 수 없는 외부효과 경계.

## 필수 의견 수용

Codex는 조수의 의견을 선택적으로 숨기거나 생략할 수 없다. 모든 의견은 원 발언자, 근거, 처리 상태를 남긴다. 기각도 가능하지만 반드시 검증 근거를 기록해야 한다. 해결되지 않은 `BLOCKED`가 있으면 최종화·commit·push를 진행하지 않는다.

READY와 사용자 승인은 정확한 산출물 digest 또는 commit SHA에 결속된다. 내용이나 SHA가 바뀌면 자동 무효화하고 재검토한다. 조수 판정에는 세션 ID·턴·메시지 ID·원 발언 증거를 붙인다.

## 최종화 절차

1. A0 산출물 후보와 검증 계획 게시.
2. A1 Claude Code와 Antigravity 독립 검토.
3. A2 모든 의견 처리와 재검증.
4. C0 stage 파일·diff·commit 메시지·검사 결과 게시.
5. C1 세 도구 commit 합의와 사용자 승인.
6. P0 fetch·원격 SHA·전체 트리·비밀정보 감사.
7. P1 세 도구 push 합의.
8. P2 사용자 최종 push 승인.
9. P3 일반 push와 로컬·추적·실원격·필수 경로 검증.

실물·UX 검증은 구체적 화면·동작 관찰을 텍스트로 남긴다. Render 등 배포가 범위에 있으면 로컬과 배포 환경의 기능 일치도 확인한다.

현재 프로젝트는 Git 저장소가 아니므로 모든 commit·push 게이트는 `BLOCKED` 상태다. 이 문서 작성은 Git 초기화나 원격 연결을 승인하지 않는다.
