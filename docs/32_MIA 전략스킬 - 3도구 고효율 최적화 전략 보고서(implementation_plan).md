### 🔴 /REDTEAM — 발견된 오류와 위험

#### 오류 1: Antigravity CLI 실행 불가 (`0x800700e8`)
- **무엇**: 스크린샷에서 `agy.exe --version` 실행 시 오류 코드 `2147942632 (0x800700e8)`
- **왜 문제인가**: 헤드리스 CLI(headless CLI, 화면 없이 명령줄로 도구를 조작하는 방식)가 작동하지 않으면 Antigravity 워커의 소켓 등록·자동 배차를 코드로 제어할 수 없음
- **영향**: C3P 자동 오케스트레이션에서 Antigravity 구간은 **파일 기반 통신(queue.jsonl)으로만 가능**. 이 자체는 작동하지만 실시간성이 떨어짐

#### 오류 2: 테스트 실행 환경 깨짐
- **무엇**: `pytest` 미설치 + `unittest discover` 경로 문제
- **왜 문제인가**: 코드 변경 후 회귀(regression, 이전에 작동하던 것이 깨지는 현상) 검증을 자동화할 수 없음. 현재 코드베이스에 테스트 파일 11개가 있지만 한 번도 실행 확인이 안 됨
- **영향**: docs/30 실험계획의 "수용 기준 검증"이 불가능

#### 오류 3: 미커밋 변경의 소유권 충돌
- **무엇**: `AGENTS.md`, `CLAUDE.md`, `GEMINI.md`를 포함한 19개 수정 파일이 어느 도구의 것인지 구분 불가
- **왜 문제인가**: 3도구가 같은 파일을 수정하면 누구의 변경이 정본인지 알 수 없음. Codex가 docs/29에서 "다른 세션의 미커밋 변경이 있어 덮어쓰지 않는다"고 명시한 이유
- **영향**: 글로벌 룰 개정의 **첫 번째 게이트가 막혀 있음**

#### 오류 4: `csc_swarm_watcher.py` 바쁜 루프(busy loop, 쉬지 않고 반복 확인하는 비효율 방식)
- **무엇**: Claude Code가 지적 — 5초마다 서브프로세스를 호출하는 구조
- **영향**: 유휴 시에도 CPU와 토큰을 소비. 사건 기반(event-driven, 변화가 생겼을 때만 반응) 방식으로 교체 필요
