## 운영 규칙

- 새 계획 문서는 두 자리 번호를 붙인다.
- 정본을 중복 생성하지 않고 기존 문서를 갱신한다.
- 관찰 사실, 사용자 제공 정보, 가설, 미확인을 구분한다.
- 외부효과가 필요한 단계는 승인 상태를 명시한다.
- 실행 실패와 실행하지 못한 검증을 숨기지 않는다.
- Codex·Claude Code·Antigravity 어느 세션이든 작업 시작·종료 시 이 폴더를 확인하고 갱신한다.
