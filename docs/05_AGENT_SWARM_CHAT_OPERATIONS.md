# `.agent-swarm` 채팅방 운영 규약

작성일: 2026-08-23 KST

## 목적

`.agent-swarm`를 Codex, Claude Code, Antigravity가 동일 프로젝트 맥락을 공유하는 공식 채팅방으로 사용한다.

## 동작 방식

1. 사용자의 새 메시지를 Codex가 `chat/ROOM.md`에 기록한다.
2. Codex가 필요한 조수에게 실제 장기 세션 메시지를 보낸다.
3. 조수는 `ROOM.md`, `docs/00_PROJECT_INDEX.md`, 자기 작업 카드를 먼저 읽는다.
4. 조수는 응답을 `chat/sessions/<tool>-<session-id>.md`에 append하고 세션 응답으로도 돌려준다.
5. Codex가 응답을 검증하고 `ROOM.md`에 중계한다.
6. 결정·실험 결과는 번호형 `docs`와 결과 폴더에 승격한다.

## 실시간성의 범위

- 장기 세션은 맥락을 유지한다.
- 새 이벤트가 생기면 Codex가 즉시 전달한다.
- 무한 파일 감시는 사용하지 않는다.
- Claude Code와 Antigravity의 직접 P2P 채널이 검증되기 전에는 Codex가 모든 중계를 담당한다.
- Claude Code 일부 세션 사이에는 P2P 메시징이 관찰됐지만, Antigravity까지 포함한 공통 채널은 아니며 세션 정체성 혼동과 공유 파일 충돌이 발생했다. 따라서 정식 경로로 채택하지 않는다.

## 역할 정렬

- Codex: 사령관, 사용자 대화, 안전 정책, 업무 분해, 최종 통합·검증.
- Claude Code: 요구사항·아키텍처·오류 경로·테스트·코드 리뷰.
- Antigravity: 독립 대안, 초보자 UX, IDE·브라우저 관점, 장시간 탐색.

## 안전 경계

- 각 조수는 자기 채널 파일만 append할 수 있다.
- 소스 파일 쓰기는 별도 작업 카드와 단일 소유자 지정 후 허용한다.
- commit, push, deploy, install, 계정 변경은 채팅방 합의만으로 승인되지 않는다.

## 허심탄회한 토론 규칙

- 성공만 보고하지 않고 기술적 한계, 실패, 불확실성, 반대 의견을 함께 남긴다.
- 상대 발언을 읽지 않은 채 독립 의견만 반복하지 않는다.
- 중요한 결정은 `제안 → 상대 검토 → 반론 또는 동의 → Codex 판정`의 최소 2회 왕복을 거친다.
- Codex가 요약할 때 원 발언자를 표시하고 의미가 다른 의견을 억지로 합치지 않는다.
- 비밀정보, 자격증명, 개인정보는 토론 투명성의 대상이 아니다.
- 상세 내부 추론 대신 검증 가능한 근거, 판단 요약, 트레이드오프를 기록한다.

## v0.2 실패와 v0.3 보정

- 도구별 채널은 동일 도구의 복수 세션에서 소유권이 충돌했다.
- 관리되지 않은 Claude Code 피어 세션의 별도 사용자 메시지가 같은 파일에 섞였다.
- 완료 보고와 디스크 상태가 일치하지 않은 append가 있었다.
- Codex가 실제 시계를 조회하지 않은 잘못된 타임스탬프를 기록했다.
- 해결: 세션별 채널, 등록부 기반 참여자, Codex 전용 SEQ 순서, 읽은 파일 해시 ACK.

기존 사고 파일과 발언은 삭제하지 않고 감사 기록으로 보존한다.
