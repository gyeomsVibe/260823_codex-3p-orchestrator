### 3. Claude Code가 정립한 범위

- **완료되고 현재 검증된 것:** CSC CLI·브로커·worker·저장소·합의/쿼럼·인증·증거 모듈, 웹 UI, 거버넌스 문서, 테스트 묶음. 현재 전체 `unittest` 63개 통과.
- **작동하지만 운영 검증이 얕은 것:** 장시간 상주, CLI 재인증·사용량 제한 처리, 프로세스 사망 후 복구, 실시간 대화 뷰어, 브로커 장애 복구.
