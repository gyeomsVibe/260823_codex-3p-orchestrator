\#\#\# \[Step 1\] 2주차 과제: 프리미엄 '오늘 뭐 먹지?' 웹앱 제작  
\- \*\*산출물\*\*: \`index.html\`, \`style.css\`, \`app.js\` (또는 단일 번들 파일)  
\- \*\*기능 스펙\*\*:  
  \- 한식/중식/일식/양식/간식 카테고리별 랜덤 추천 및 필터링  
  \- 고해상도 이모지 & 추천 메뉴 상세 설명 (칼로리/특징 등)  
  \- 최근 추천 이력 (Recent 3 history) 로컬스토리지 연동  
  \- 모바일 완벽 대응 반응형 글래스모피즘 UI

\#\#\# \[Step 2\] 3주차 과제 A: GitHub & Render.com 배포 준비  
\- \*\*산출물\*\*: \`server.js\` (또는 정적 서빙 스크립트), \`package.json\`, \`.gitignore\`, \`README.md\`  
\- \*\*실행 절차\*\*:  
  \- 에이전트가 로컬 Git 저장소 초기화 (\`git init\`)  
  \- 민감정보 배제용 \`.gitignore\` 작성  
  \- Render 환경 변수(\`PORT\`) 자동 대응 웹 서버 세팅 및 로컬 빌드/실행 검증

\#\#\# \[Step 3\] 3주차 과제 B: 로컬 AI (Ollama \+ \`qwen3.5:0.8b\`) 무인 자동화 검증  
\- \*\*실행 절차\*\*:  
  \- 에이전트가 현재 Windows 환경의 Ollama 설치 여부 직접 진단 (\`ollama \--version\`)  
  \- 미설치 시 설치 절차 안내 / 설치되어 있다면 \`qwen3.5:0.8b\` 모델 즉시 풀링  
  \- 에이전트가 백그라운드 터미널로 모델을 구동하고 \`"안녕하세요"\` 질의를 전송하여 한국어 응답 수신 검증

\#\# 4\. 🧭 역질문 (Strategic Lead: 맞춤형 진행을 위한 확인)

윤겸 님의 환경과 선호에 맞춰 가장 빠르고 정확하게 가시적인 성과물을 뽑아내기 위해 아래 \*\*3가지 질문\*\*을 확인하고자 합니다.

1\. \*\*\[구현 형태\]\*\*
   \- \*\*(추천)\*\* 즉시 브라우저에서 열어볼 수 있는 모던 프리미엄 단일 웹앱(HTML/CSS/JS)으로 시작하여 Render 배포용 파일(\`package.json\` 등)까지 일괄 생성할까요?  
2\. \*\*\[GitHub & Render 연동 방식\]\*\*  
   \- 현재 본인의 GitHub 저장소 URL이 준비되어 있어 바로 원격 푸시를 진행할지, 아니면 로컬에서 Git 커밋 및 Render 배포용 번들을 먼저 완벽히 구성해둘지 결정해 주세요.  
3\. \*\*\[로컬 AI (Ollama) 상태\]\*\*  
   \- 현재 노트북에 Ollama가 이미 설치되어 있는지, 아니면 제가 지금 즉시 시스템 환경을 진단하여 확인해 드릴까요?
