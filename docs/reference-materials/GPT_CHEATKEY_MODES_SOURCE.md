## **GPT 실전 치트키 모드**

**1\. SELFREFINE**  
지금 답변을 스스로 다시 검토해서 더 좋은 버전으로 수정해.  
👉 초안보다 완성도와 논리적 결점 보완율이 크게 올라갑니다.
**2\. REDTEAM**  
반대 입장에서 허점과 문제점을 최대한 찾아줘.  
👉 기획 검증, 리스크 스캔, 반론 방어 시 최고의 효율을 냅니다. 

**3\. ELI10**  
10살도 이해할 수 있게 쉽게 설명해.  
👉 복잡한 기술 문서, 개념, 전문 용어를 대중적 언어로 정제합니다. 

**4\. DEEPDIVE**  
얕게 말하지 말고 깊이 분석해.  
👉 단순 요약을 넘어 심층적인 원인 분석과 자료 조사를 수행합니다. 

**5\. ALT3**  
다른 대안 3가지를 제안해.  
👉 아이디어가 고갈되었을 때 의사결정의 스펙트럼을 넓혀줍니다. 

**6\. CRITIC**  
칭찬하지 말고 냉정하게 평가해.  
👉 감정적 필터를 제거하고 객관적이고 뼈아픈 피드백을 수집합니다. 

**7\. OPTIMIZE**  
같은 내용을 더 효율적이고 더 좋은 결과가 나오도록 개선해.  
👉 작성된 문장, 비즈니스 기획서, 실행 계획의 군더더기를 제거합니다. 

**8\. STEPBYSTEP**  
순서대로 단계별로 설명해.  
👉 논리적 비약을 방지하고, 복잡한 다단계 워크플로우를 설계할 때 유용합니다. 

**9\. EXPERT**  
이 분야 전문가의 관점에서 분석해.
👉 범용적인 답변을 거부하고 특정 전문 도메인의 컨설턴트 페르소나를 강제합니다. 

**10\. STRUCTURED FEW-SHOT (구조화 및 예시 고정)**  
"내가 원하는 최종 출력 양식과 완벽한 예시(Few-Shot)를 아래와 같이 줄 테니까, 이 구조와 톤앤매너를 100% 동일하게 유지해서 내 입력 데이터를 처리해."  
👉 **활용 목적 및 기대 효과**: AI가 뻔하고 지루한 답변(AI Slop)을 생성하는 것을 원천 차단하고, 사용자가 원하는 포맷(마크다운, JSON, 특정 템플릿 등)의 데이터 규격을 칼같이 지키도록 강제할 때 가장 강력합니다. 예시를 1\~2개만 정확히 제공해도 답변의 정확도와 신뢰 신호(Signal)가 비약적으로 상승합니다.
