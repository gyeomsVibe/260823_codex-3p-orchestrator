## 0. 결론 먼저

1. **가장 위험한 충돌은 룰이 아니라 설정입니다.** Codex가 `approval_policy = never` + `sandbox_mode = danger-full-access` + 브라우저 전 출처 `full_cdp_access = allow`로 돌고 있습니다. 글로벌 룰 P2("샌드박스·권한 프롬프트를 약화하지 않는다")를 **Codex 자신이 위반한 상태**입니다. 사령관으로 격상하려는 도구가 가장 무방비합니다.
2. **역할 모델이 3개가 동시에 살아 있습니다.** (a) `codex-3p-orchestrator` 스킬: Brain/Immune/Hands, (b) README·docs/07~13: 감각기/두뇌/면역계/Ollama 노예, (c) `docs/23`: PLAN/BUILD/VERIFY. 사용자 신규안(Codex 지휘 + Antigravity 일꾼 + Claude 분리)은 이 셋 **모두와** 충돌합니다.
3. **`claude mcp serve`가 Codex에 등록돼 있습니다.** 이 저장소 옆 프로젝트의 자체 실측(F28)에 따르면 Claude의 권한 설정을 무시하고 `Bash`·`Write` 포함 28종 도구를 노출합니다. Codex가 승인 없이 돌기 때문에 **무승인 원격 push 경로**가 열려 있습니다. Claude 분리 결정과도 맞지 않으니 1순위로 제거해야 합니다.
4. **사용자 제안의 방향은 타당합니다.** 다만 "Antigravity가 Codex 토큰을 대신 쓴다"는 결과를 **짧게 요약해 돌려받을 때만** 성립합니다. 긴 출력을 그대로 받으면 Codex 컨텍스트가 똑같이 소모됩니다.

## 2. 충돌 지점 (심각도순)

### 🔴 K1. Codex 무방비 실행 vs 글로벌 룰 P2
* **증거**: `~/.codex/config.toml` — `approval_policy="never"`, `sandbox_mode="danger-full-access"`, `browser_use.default_origin_policy.full_cdp_access="allow"`.
* **충돌**: 같은 머신의 `~/.codex/AGENTS.md` P2 "Never weaken a warning, sandbox, permission prompt" / "Without explicit approval, do not deploy, publish…".
* **영향**: Markdown 룰은 "행동 지침"일 뿐입니다(룰 스스로 adapter 절에서 인정). 강제력은 설정에 있고, 설정이 전부 열려 있습니다. 모든 로그인된 사이트에 대한 브라우저 전권도 포함됩니다.
* **역설**: 일꾼인 `antigravity-bridge`는 "자동승인 false, 샌드박스 true"로 **강화된 포크**인데, 지휘하는 Codex는 무샌드박스입니다.

### 🔴 K2. `claude-code` MCP (`claude mcp serve`) — 권한 우회 경로 + 분리 결정 위배
* **증거**: Codex MCP 목록에 `claude-code: claude mcp serve`. `260718_.../mcp/claude-code-subordinate/README.md` 실측 F28: deny 규칙 30개가 **무시**되고 `git push --dry-run`이 실행됨. 같은 문서 F25: `agy`가 지시받지 않은 commit·push를 실제로 수행.
* **충돌**: 사용자 신규안(Claude 분리) + K1(무승인) + P2.
* **조치**: 제거. `local-agent-runtime`도 Claude 세션을 유지하는 기능이 핵심이므로 Antigravity 전용으로 축소하거나 제거.

### 🔴 K3. 역할 모델 3중 경쟁
| 출처 | Codex | Claude Code | Antigravity |
|---|---|---|---|
| `codex-3p-orchestrator` 스킬 (Antigravity 전용 설치) | Brain | Immune(구현) | Hands & Eyes(QA) |
| README·docs/07~13 | 두뇌/사령관 | 면역계 | 감각기·대면창구 (+Ollama 노예) |
| `docs/23` + 루트 3개 어댑터 | PLAN | BUILD | VERIFY(구현 수정 금지) |
| **사용자 신규안** | 지휘자 | **분리·독립** | **Codex의 일꾼(구현 포함)** |

신규안에서 Antigravity는 VERIFY(읽기 전용)에서 **쓰기 권한을 가진 일꾼**으로 바뀝니다. 권한 경계가 반대로 뒤집히므로 문구 치환으로 끝나지 않고, 검증자를 따로 둘지 새로 정해야 합니다(§4 참고).

### 🟠 K4. 글로벌 룰에 프로젝트 전용 내용 혼입
* 룰 스스로 "keep global guidance limited to stable defaults"라고 쓰면서, 프로젝트 전용인 **C3P 명명 절**과 **vibe-check 트리거 문구**를 3개 도구 전역에 상시 로드합니다.
* 범위도 충돌합니다. 글로벌 룰은 "C3P 절차는 `codex-3p-orchestrator` 프로젝트에서만"이라고 하는데, 이 저장소(`260912_...`)는 `docs/23`으로 C3P 절차 전체를 적용합니다.

### 🟠 K5. 스킬 3중 복제와 이미 시작된 드리프트
* 22개 스킬이 3곳에 **복사본**으로 존재합니다(링크가 아님). 동기화가 수동이라 **이미 어긋났습니다**: `mia-strategic` Claude 3,269B vs Codex 3,252B.
* 슬래시 모드 계열 하나의 계약이 `slash-prompt-modes`(총괄) + 10개 개별 별칭 + (Claude 목록상) 대문자 어댑터 10개로 **최대 21개 항목**으로 노출됩니다. 스킬 설명 목록은 매 세션 컨텍스트에 실립니다.
* `mia-strategic`은 Antigravity에 없고, `codex-3p-orchestrator`는 Antigravity에만 있습니다. 같은 발동 문구가 도구마다 다르게 동작합니다.

### 🟠 K6. MCP 중복·과적재
* `notebooklm`·`vibe-clinic`이 3개 도구에 모두 등록돼 있고, Codex는 MCP 6 + 플러그인 15입니다(computer-use 2종·pdf 2종 중복).
* 웹 근거: 도구 정의 1개당 200~500토큰이며, 서버가 늘면 도구 이름 환각·파라미터 오선택이 증가합니다(§6).

### 🟡 K7. 자율성 규칙 충돌 (메모리 vs 프로젝트 룰)
* Claude 메모리(260718): "묻지 말고 판단해서 진행"
* `docs/23` + 루트 `CLAUDE.md`: "인계 후 Codex의 상태 전이 전까지 쓰기 중지"
* 글로벌 P1: "고가치 질문 1개만"
* → 같은 사용자에 대해 "자율 진행", "정지 대기", "최소 질문"이 동시에 걸립니다.

### 🟡 K8. Codex 자동 메모리 생성
* `generate_memories = true`. 룰이 바뀌어도 과거 역할 모델(Brain/Immune 등)이 메모리에 남아 재주입될 수 있습니다. 내용은 **UNKNOWN**(미열람).

### 🟡 K9. 과한 지침 (연구 기준)
* 글로벌 룰 127줄 ≈ 12KB가 3개 도구 모두에 매 턴 로드됩니다. 공개 분석은 80~150줄부터 준수율 하락, 컨텍스트 파일이 성공률을 올리지 않고 추론 비용을 약 20% 늘린다고 보고합니다(§6).
* "CPST", "Prefix invariance", "preregistered A/B" 같은 예산 거버넌스 절은 에이전트가 실행할 수 없는 추상 지시입니다. 매 턴 비용만 들고 행동 변화는 측정되지 않았습니다(룰 스스로 `UNMEASURED` 규정).

### 6.3 스킬

* Codex: `sandbox_mode = "workspace-write"`, `approval_policy = "on-request"`, 브라우저 `default_origin_policy`를 `ask`로 복원.
* 이 항목은 **보안 설정 변경**이므로 제가 수행하지 않습니다. 사용자가 직접 변경하는 것을 권고합니다.

### 6.5 프로젝트(이 저장소)
* 루트 `CLAUDE.md`(BUILD 역할)는 Claude 분리 후 의미가 없습니다. `docs/23`은 A안 채택 시 "Codex PLAN/CLOSE + Antigravity 작업 + 테스트 게이트"로 축소 개정이 필요합니다. **`docs/23`의 변경 권한은 규칙상 Codex 계획 대화창 또는 사용자에게 있어** 제가 수정하지 않습니다.
