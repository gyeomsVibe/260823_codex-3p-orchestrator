# Codex Task Card

- Goal: 3대 도구 통합 병렬 실험을 안전하게 설계하고, 사용자 승인에 따라 가시적 결과물을 완성한다.
- Mode: scoped-write
- Owned paths: `docs/**`, `.agent-swarm/**`, 사용자 승인 후 결정되는 구현 폴더
- Forbidden effects: 승인 없는 Git 초기화·push·Render 배포·설치·계정 변경
- Deliverable: MIA 결정문, 단계별 실습계획, 세션 검증 로그, 최종 구현과 테스트 결과
- Acceptance: 사실/가설/미확인 구분, 3도구 역할 분리, 외부효과 게이트, 실제 실행 검증
